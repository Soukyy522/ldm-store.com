11. JIKA DEVICE OWNER UTAMA IKUT PENDING
==================================================

Pada upgrade normal dari Tahap 14, Device A yang sudah pernah terdaftar
akan mempertahankan status active.

Kalau instalasi benar-benar fresh dan SEMUA perangkat menjadi pending,
Owner belum punya perangkat active untuk menyetujui Device A.
Gunakan Supabase SQL Editor sebagai recovery satu kali:

select
    d.id as device_id,
    d.client_device_id,
    d.device_name,
    d.status,
    p.username,
    p.role
from public.devices d
join public.profiles p on p.id = d.user_id
where d.deleted_at is null
order by d.last_seen_at desc;

Pastikan UUID perangkat benar-benar milik Device A Owner.
Lalu aktifkan HANYA perangkat tersebut:

update public.devices
set status = 'active'
where id = 'PASTE_DEVICE_UUID_OWNER_A_DI_SINI';

Sesudah itu login kembali di Device A dan lakukan approval perangkat lain
melalui dashboard -> Perangkat Cloud.
