CARA MEMASANG DI GITHUB
------------------------
1. Buka repository aplikasi di GitHub.
2. Buka folder js.
3. Pilih Add file > Upload files.
4. Unggah reporting-service.js dan timpa file lama.
5. Commit perubahan.
6. Kembali ke folder utama repository.
7. Unggah service-worker.js, lima file HTML, dan VERSION.txt.
8. Commit perubahan.
9. Tunggu proses deployment GitHub Pages selesai.

Jika memakai hosting selain GitHub, unggah file ke posisi folder yang sama.
Jangan memindahkan reporting-service.js keluar dari folder js.

BERSIHKAN CACHE SATU KALI SETELAH DEPLOY
-----------------------------------------
Buka aplikasi, tekan F12, pilih Console, lalu jalankan:

(async () => {
    const registrations = await navigator.serviceWorker.getRegistrations();
    await Promise.all(registrations.map(item => item.unregister()));
    const names = await caches.keys();
    await Promise.all(
        names.filter(name => name.startsWith("ldm-")).map(name => caches.delete(name))
    );
    location.reload();
})();

Kode tersebut tidak menghapus transaksi atau localStorage.
