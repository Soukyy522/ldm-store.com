Pertanyaan umum

Informasi sebelum menggunakan aplikasi

Apakah LocDailyMar dapat digunakan melalui HP?

Ya. Tampilan dibuat responsif untuk HP dan desktop. Jika dipasang sebagai PWA, aplikasi dapat dibuka seperti aplikasi dari layar utama perangkat.

Apakah data antarperangkat dapat tersambung?

Perangkat yang login dan terhubung ke Store ID yang sama dapat memakai data Cloud toko yang sama sesuai role dan izin akunnya.

Apakah tersedia masa percobaan?

Tersedia trial Warung Sederhana selama 14 hari sesuai ketentuan pada halaman lisensi.

Apa yang terjadi jika masa lisensi habis?

Akses paket bulanan atau tahunan ditangguhkan sementara sampai diperpanjang. Data toko tidak otomatis dihapus. Paket Lifetime tidak mempunyai masa kedaluwarsa periodik.

Bagaimana proses pembeliannya?

Pilih paket pada halaman Lisensi, isi data customer, lalu bayar melalui Midtrans. Setelah pembayaran terverifikasi, License Key, Store Code, Store UUID, dan Network ID ditampilkan langsung pada halaman untuk disimpan customer.
