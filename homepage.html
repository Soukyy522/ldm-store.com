3 Mode Operasional

Satu aplikasi, tampilan dan aturan kerja menyesuaikan jenis usaha

Mode dipilih per toko/cabang. Cabang Retail dapat tetap menjadi Retail sementara cabang lain menggunakan Kafe atau Warung tanpa mencampur katalog secara otomatis.

☕

Mode Kafe

Untuk coffee shop, kedai minuman, bakery, dan usaha menu siap saji.

  • Menu visual dengan gambar yang dapat dikustomisasi.
  • Soft Stock: stok 0 tidak memblokir transaksi.
  • Indikator stok kritis dan navigasi inventori disederhanakan.
🍜

Mode Warung

Untuk warung makan, kantin, warung kopi, dan usaha campuran barang + menu.

  • Tampilan lebih padat dan cepat.
  • Soft Stock untuk barang/menu yang tetap bisa dijual saat stok sistem 0.
  • Navigasi hanya menonjolkan pekerjaan yang umum dipakai.
🛒

Mode Toko Ritel

Untuk minimarket, sembako, frozen food, dan toko dengan kontrol stok fisik ketat.

  • Tanpa gambar produk di Kasir agar katalog besar tetap ringan.
  • Strict Stock: transaksi ditolak jika stok tidak mencukupi.
  • Kartu Stok, Stock Opname, Retur, dan menu inventori lengkap tetap tersedia.
Penyimpanan yang terkontrol

Database menyimpan data, Storage menyimpan file.

Nama produk, transaksi, stok, laporan, dan pengaturan disimpan sebagai data terstruktur. Gambar menu, foto absensi, dan bukti pengeluaran disimpan sebagai file di Supabase Storage sehingga database tidak dipenuhi data gambar besar.

1
File dikompresi sebelum uploadGambar menu Kafe diperkecil agar penggunaan Storage lebih hemat. Katalog Warung dan Retail tidak memakai gambar item.
2
Database hanya menyimpan pathProduk menyimpan alamat file kecil, bukan base64 gambar.
3
Retensi membersihkan data teknis/file lamaAudit teknis, foto lama, dan gambar produk yatim dapat dibersihkan otomatis sesuai batas waktu.
✓

Pertanyaan umum

Informasi sebelum menggunakan aplikasi

Apakah LocDailyMar dapat digunakan melalui HP?

Ya. Tampilan dibuat responsif untuk HP dan desktop. Jika dipasang sebagai PWA, aplikasi dapat dibuka seperti aplikasi dari layar utama perangkat.

Apakah data antarperangkat dapat tersambung?

Perangkat yang login dan terhubung ke Store ID yang sama dapat memakai data Cloud toko yang sama sesuai role dan izin akunnya.

Apakah saya bisa mencoba 3 Mode tanpa akun?

Ya. Ya. Tekan Coba Demo untuk masuk ke halaman sandbox aplikasi tanpa login dan tanpa License Key. Sandbox tidak memuat Supabase untuk tindakan data dan tidak menyimpan transaksi, laporan, stok, atau perubahan lain.

Apakah file dan database akan terus bertambah tanpa batas?

LocDailyMar memisahkan data terstruktur dan file. File media disimpan di Storage, sedangkan kebijakan retensi dapat membersihkan audit teknis, foto lama, dan file gambar yang sudah tidak digunakan. Histori transaksi penting tidak ikut pembersihan otomatis.

Apakah tersedia masa percobaan?

Tersedia trial Warung Sederhana selama 14 hari sesuai ketentuan pada halaman lisensi.

Apa yang terjadi jika masa lisensi habis?

Akses paket bulanan atau tahunan ditangguhkan sementara sampai diperpanjang. Data toko tidak otomatis dihapus. Paket Lifetime tidak mempunyai masa kedaluwarsa periodik.

Bagaimana proses pembeliannya?

Pilih paket pada halaman Lisensi, isi data customer, lalu bayar melalui Midtrans. Setelah pembayaran terverifikasi, License Key, Store Code, Store UUID, dan Network ID ditampilkan langsung pada halaman untuk disimpan customer.
