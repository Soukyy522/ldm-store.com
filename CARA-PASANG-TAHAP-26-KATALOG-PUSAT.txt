LOCDailyMar 26.0 - KATALOG BARANG PUSAT DAN SINKRON CABANG
===========================================================

HASIL AKHIR
-----------
1. Kontrol Pusat mempunyai bagian "Update Data Barang Cabang Lain".
2. Data yang mengikuti cabang pusat:
   - barcode dan nama barang
   - kategori
   - satuan dasar, satuan beli, dan konversi
   - harga beli
   - harga jual
   - nama, jenis, nilai, harga, syarat jumlah, dan periode promo
3. Stok dan tanggal kedaluwarsa tetap berbeda pada setiap cabang.
4. Owner Cabang tidak dapat menambah, mengedit, menghapus, atau mengubah harga/promo.
5. Hanya Owner Utama pada toko pusat yang dapat mengubah master barang.

CARA MEMASANG
-------------
1. Unggah/ganti seluruh file aplikasi versi 26.0.0 pada hosting.
2. Buka Supabase Dashboard project APLIKASI (bukan project server lisensi).
3. Pilih SQL Editor > New query.
4. Buka file:
   supabase/sql/24-stage26-central-product-catalog-sync.sql
5. Salin seluruh isi file, tempel ke SQL Editor, lalu tekan RUN satu kali.
6. Buka file:
   supabase/sql/24-stage26-verify.sql
7. Salin seluruh isi, RUN, dan pastikan kolom pemeriksaan bernilai true.
8. Buka aplikasi, login sebagai Owner Utama, lalu buka Kontrol Pusat.
9. Pada "Update Data Barang Cabang Lain":
   - tekan "Sinkronkan sekarang" untuk satu cabang; atau
   - tekan "Sinkronkan semua cabang" untuk semua cabang.
10. Biarkan "Ikuti pusat" aktif agar perubahan berikutnya tersinkron otomatis.
11. Jika aplikasi dipasang sebagai PWA, buka Aplikasi & Update dan pasang versi baru.

CARA KERJA
----------
- Sinkron pertama membuat/mencocokkan produk cabang berdasarkan tautan UUID,
  barcode, atau nama unik untuk produk tanpa barcode.
- Produk baru dari pusat dibuat di cabang dengan stok awal 0.
- Produk yang telah tertaut akan terus menerima perubahan katalog pusat.
- Barang lama yang hanya ada di cabang tidak dihapus otomatis, sehingga histori
  cabang tetap aman. Owner Utama dapat meninjaunya sebelum tindakan lanjutan.
- Saat sinkron, field stok dan tanggal kedaluwarsa cabang tidak disentuh.
- Perubahan pusat memicu update baris products cabang; perangkat cabang menerima
  perubahan melalui Realtime dan memperbarui cache dataBarang.

ATURAN STOK
-----------
- Penjualan cabang mengurangi stok cabang tersebut saja.
- Goods Receipt cabang menambah stok cabang tersebut saja.
- Retur, transfer stok, dan Stock Opname bekerja pada toko yang terkait.
- Harga beli dari Goods Receipt cabang tidak mengganti harga beli master pusat.
- Perubahan harga resmi dilakukan Owner Utama di barang.html pada cabang pusat.

JIKA OWNER UTAMA TIDAK BISA MENGEDIT BARANG
-------------------------------------------
Pastikan akun sedang berpindah ke toko pusat. Owner Utama yang sedang membuka
toko cabang akan memperoleh mode hanya lihat agar tidak mengubah salinan cabang.

JIKA PANEL MENAMPILKAN ERROR RPC TIDAK DITEMUKAN
-----------------------------------------------
SQL Tahap 26 belum dijalankan pada project Supabase aplikasi yang benar. Jalankan
file instalasi pada project yang URL-nya sama dengan js/supabase-config.js.
